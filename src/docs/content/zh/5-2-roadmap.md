## 当前平台支持

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| macOS（Apple 芯片） | ✅ 已发布 v0.6.5 | Electron 桌面版，内置 Go 后端 |
| macOS（Intel） | — | 当前安装包不支持 |
| Windows | 🚧 正在开发中 | — |
| Linux 桌面 | 🚧 正在开发中 | 远程中继本身可部署在 Linux 服务器上 |
| iOS | ✅ 可用 | 查看与继续对话、审批、iOS 灵动岛、Siri |
| 远程中继 | ✅ 可用 | Node.js + SQLite，自托管，systemd 运行 |
| 局域网直连 | 🧪 Beta | iPhone 与 Mac 同网直连，失败回退云端 |

## v0.6.5 新特性

- **GitHub Idea 调度**：监听 Issue，按岗位、能力标签与负载推荐数字员工，支持幂等入队、历史审计和失败重派。
- **iOS 与 Siri**：支持查询数字员工、查看进度、下发任务和询问前台，并完善深链、任务规划与灵动岛同步。
- **远程使用优化**：站点登录有效期延长至 30 天，补齐移动端凭据、用量小组件和异常恢复链路。

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 安装包未签名 | 首次打开需要右键打开或清除隔离属性；签名与公证需要单独的发布流程 |
| iOS 灵动岛实时性 | 尚未接入 APNs Live Activity 远程推送，App 被系统挂起后不保证实时 |
| 局域网直连不加密 | HTTP + 签名认证，仅适用于可信网络 |
| 中继为单站门禁 | 尚未提供多用户账号与细粒度 RBAC |
| 引擎能力差异 | 执行前拦截、图片、用量等能力因引擎而异 |

## 演进方向

以下方向来自产品设计文档中明确记录的后续计划，**不代表已承诺的发布时间**：

- **Windows 与 Linux 桌面版**：当前正在开发中。
- **局域网直连加密**：设计中预留了升级为自签名 TLS + App 证书指纹固定的方案，无需购买证书。
- **中继能力扩展**：可选 TLS、多用户与按员工的访问控制；以出站 WebSocket 替代长轮询以降低延迟。
- **流程编排增强**：条件节点的 AI 判定、断点续跑等能力已在数据结构中预留。
