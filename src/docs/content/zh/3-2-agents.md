## 概览

数字员工 = **一个本机 AI 引擎** + 姓名、岗位、像素水母头像、工作区、权限策略与技能。你可以从人才市场选择预制岗位，也可以从零自定义全部信息。下面的交互演示可以实时体验员工的定制过程：

## 招聘数字员工

```text
打开人才市场
        ↓
选择预制岗位或自定义
        ↓
选择引擎 + 像素水母颜色 + 工作区
        ↓
写入人设、权限策略和预置技能
        ↓
创建员工 + 主对话 → 出现在员工列表
```

人才市场当前提供 6 个官方岗位模板：

| 岗位 | 预置员工 |
| --- | --- |
| 产品经理 | 林晓晴 |
| 前端工程师 | 沈清禾 |
| Java 后端程序员 | 陈思语 |
| Go 后端程序员 | 陆景行 |
| 全栈开发工程师 | 苏晚舟 |
| 运维工程师 | 韩予澈 |

> [!NOTE]
> 预制岗位只是起点，不代表员工已拥有所有外部工具或账号。引擎必须已在本机安装并登录；新员工默认进入「未分组」，部门不是必填项。

## 像素水母：员工的身份标识

每位员工都有一只像素水母，**颜色在创建时保存**，共 12 种。水母的动作与呼吸灯反映当前状态，即使收起侧栏也能一眼认出谁在忙：

| 状态 | 表现 |
| --- | --- |
| 运行中 | 浅橙呼吸灯 |
| 空闲、无未读 | 浅绿呼吸灯 |
| 完成未读 | 蓝色呼吸灯 |
| 报错未读 | 错误态 |

状态展示的统一优先级是：**报错 > 待审批 > 运行中 > 完成未读 > 普通空闲**。打开对应对话后，终态未读会被清除。

## 工作区与权限策略

工作区是员工执行任务的默认目录，引擎进程会以它作为当前目录启动。每位员工还有一组**相互独立**的权限开关：

| 开关 | 作用 |
| --- | --- |
| 写入 | 是否允许修改文件 |
| 联网 | 是否允许网络请求（可配合域名白名单） |
| 删除 | 是否允许删除；**允许写入不等于允许删除** |
| 限制工作区 | 开启后只能在工作区内读写；路径会先规范化（处理 `..` 与符号链接）再检查越界 |

> [!WARNING]
> 关闭工作区限制只代表允许访问更广的路径，**Hard Deny、写入与删除开关依然独立生效**。

## 技能商店

技能是员工可以按需加载的专业操作说明与工具配置：

1. 在技能商店浏览技能，查看说明、来源、依赖与所需权限；
2. 选择一位员工安装；
3. 执行任务时，平台只把**该员工已启用的技能**整理成精简说明注入提示词；
4. 电脑端与移动端设置使用同一接口安装、启停或卸载。

技能的边界：

- 安装技能**不会自动安装**它依赖的外部程序、账号或凭据；
- 技能说明**不能突破** Hard Deny、员工权限和工作区边界；
- 卸载只移除能力关联，不会删除技能曾经创建的业务文件。

## 组织与分组

分组用来表达员工所属部门，也是快速筛选的维度。工作台侧栏优先按**最近活跃**排序，并支持姓名搜索与分组筛选。分组只用于组织与展示，**不会自动授予技能或文件权限**。

## 复制与解聘

- **复制**：以源员工的人设、引擎、工作区和策略为初始值创建新员工；不复制对话 Session、任务历史与未读状态。
- **解聘**：先停止运行中的任务，可选择把重要经验整理为[离职记忆](/docs/3-7-memory)，再删除员工及关联数据，并立即从电脑与手机端移除。解聘必须显式确认。
