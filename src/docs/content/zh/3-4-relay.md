## 概览

远程中继让你在手机或平板上查看电脑里的数字员工、对话与任务状态，并继续派发任务、处理审批。它的设计原则只有三条：

1. **电脑只出站**：电脑主动连接中继，服务器永远不会主动连回电脑；
2. **中继只缓存**：真相在电脑上，中继只保存按实例分片的缓存镜像与指令信箱；
3. **部署在你自己的服务器上**：数据不经过任何第三方平台。

## 拓扑

```text
手机 / 平板  ──HTTP(S)──▶  远程中继（你的服务器）  ◀──出站长轮询 + 推送──  你的电脑
                              │                                      │
                         SQLite 缓存镜像                         RemoteBridge
                         + 指令信箱                              ActionRegistry
```

- 一个中继可以连接**多台电脑**，每台电脑是一个实例；
- 中继的技术栈：Node.js + TypeScript + Express + SQLite，默认端口 `3080`；
- 电脑端由 Go 后端中的 **RemoteBridge** 负责注册、心跳、长轮询与推送镜像。

## 指令信箱

手机对电脑的每一个操作，都是向该实例的指令信箱投递一条指令：

| 状态 | 含义 |
| --- | --- |
| `pending` | 已入队，等待电脑领取 |
| `leased` | 电脑已通过长轮询领取，正在执行（带租约） |
| `done` | 执行完成，结果已回传 |
| `error` / `rejected` | 执行出错，或指令未在电脑端注册而被拒绝 |
| `expired` | 租约超时未回传结果 |

> [!IMPORTANT]
> 中继只能投递**已注册的 action**；电脑端必须有同名处理器才会执行，未注册或版本不匹配的指令一律回写 `rejected`，禁止盲跑。

## 同步了什么

| 会同步 | 不会同步 |
| --- | --- |
| 员工列表与状态摘要 | 本机文件系统 |
| 任务与运行状态 | 完整的引擎日志 |
| 移动端可见的结构化消息（含命令卡片与审批字段） | 凭据、密钥等敏感配置 |
| 查看态与未读状态（双向） | — |

客户端按稳定的消息 ID **幂等合并**，网络重连导致的重复送达不会产生重复内容；终态之后再以电脑端快照校准。

## 手机能做什么

- 恢复最近的实例、员工与会话，直接回到上次的对话；
- 发送任务、上传图片附件、查看任务队列；
- 处理待审批命令——与电脑端是**同一条审批记录**；
- 修改员工设置、通知偏好与 JEV 自动审核等配置。

实际的引擎与工作区仍运行在电脑上：**中继不会在云端运行数字员工，电脑离线时任务也不会凭空完成。**

## 离线与弱网

- 电脑离线时，手机仍可读取最近的缓存镜像并明确标注「离线」，**不会静默切换到其他电脑**；
- 投递的指令会留在信箱中，等电脑上线后再执行；
- 网络波动时客户端会退避重连、携带游标补齐遗漏事件，游标失效则拉取最新快照；
- 短暂断线不会被误判为任务失败。

## 设备会话

- 每台移动设备都有**独立的设备会话**，可以在管理页查看、撤销或重新解锁；
- 撤销后该设备的后续请求与事件连接立即被拒绝；
- 踢设备下线**不会停止**电脑上已经开始的任务。

## 局域网直连（Beta）

在同一局域网（包括 iPhone 个人热点）内，iPhone 可以绕过云端中继直接连接电脑：

- 电脑开启独立的局域网监听器，只绑定私网地址，通过 Bonjour 广播 `_atolla._tcp`；
- iPhone 扫描配对二维码生成独立设备密钥，后续每个请求都带设备 ID、时间戳、nonce 与 HMAC 签名，电脑验签并拒绝重放；
- 局域网不可达时，自动回退到云端中继。

> [!WARNING]
> 局域网直连使用 HTTP，签名可以防篡改与重放，但**内容本身不加密**，请只在可信网络中使用。
