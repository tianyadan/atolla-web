## 数据主权：本机即真相

Atolla 的所有业务数据以**你的电脑**为准：

| 数据 | 位置 |
| --- | --- |
| 员工、对话、消息、审批、队列、审计 | 本机数据库（默认 SQLite） |
| 代码与文件 | 员工的工作区，始终在本机 |
| 引擎账号与 Session | 各引擎 CLI 自身管理 |
| 移动端可见的镜像 | 你自己部署的中继，按 `instance_id` 分片缓存 |

中继上只有**缓存镜像 + 指令信箱**。实例离线时，手机读取的是最近的镜像并明确标注离线。

## 中继的安全设计

### 只出站，不入站

电脑通过出站长轮询领取指令、推送快照，**服务器永不主动 TCP 连回电脑**。你的电脑不需要公网 IP，也不需要开放任何入站端口。

### 两套独立的密码

| 密码 | 生成方 | 用途 | 生命周期 |
| --- | --- | --- | --- |
| 网站门禁密码 | 部署时由你设置 | 浏览器 / 手机登录中继站点 | 长期，可修改 |
| 实例绑定密码 | **电脑本地生成**（6 位数字 + 字母） | 实例注册、心跳、长轮询与快照 | 短期，可轮换与吊销 |

- 两类密码**只保存哈希**（门禁密码使用 bcrypt，cost 12），不明文落库、不进日志；
- 六位实例密码**禁止由服务器生成**，服务器只接收和校验；
- 吊销后旧密码立即失效。

### 防爆破与会话

- 网站登录按 IP 限速，连续失败会被临时锁定，并使用统一的错误文案；
- 实例注册与鉴权同样限速；可额外配置 `RELAY_INSTANCE_BOOTSTRAP_TOKEN`，要求首次注册携带引导令牌；
- 登录后签发短期 JWT（HS256，生产环境必须配置 `RELAY_JWT_SECRET`）；
- 只有在可信反向代理之后才开启 `RELAY_TRUST_PROXY`，否则伪造的 `X-Forwarded-For` 会被忽略。

### 受限的指令集

中继只能投递电脑端**已注册的 action**，未注册或版本不匹配的指令会被拒绝；设备侧 RPC 也经过受限注册表校验名称与参数。

## 关于 HTTPS

中继**不强制 HTTPS**，允许 `http://IP:端口` 直接运行，方便在内网或测试环境快速部署。

> [!WARNING]
> 在公网使用裸 HTTP 时，绑定密码与内容存在被窃听的风险。系统通过短期有效、可吊销与限速来降低风险，但我们**强烈建议**在公网部署时通过 Nginx、Caddy 等反向代理配置 TLS 证书。

## 局域网直连的安全模型

- 局域网服务**默认关闭**，显式启用并完成设备配对后才监听，且只绑定私网地址；
- 不复用、不暴露电脑上的管理后台 API；
- 配对生成独立设备密钥，后续请求带时间戳、nonce 与 HMAC 签名，拒绝重放与时钟漂移；
- 可随时在电脑上撤销设备；
- HTTP 不提供内容保密性，请只在可信网络中使用。

## 本机侧的保护

- 桌面版的 Go 后端运行在回环地址 `127.0.0.1:8080`，`AVATAR_ALLOWED_IPS` 默认也只允许 `127.0.0.1`；
- 本机图片回显拒绝 `.ssh`、`.aws`、Keychains 等敏感目录；
- 数据库与服务器凭据加密保存，不在对话与日志中回显。
