## 概览

**GitHub Idea 调度**（v0.6.5 新增）让 Atolla 监听 GitHub Issue，自动把新的想法或需求派给最合适的数字员工，进入它的任务队列执行。

## 工作流程

```text
GitHub Issue 事件（Webhook）
        ↓
校验 Webhook，登记来源修订
        ↓
按岗位、能力标签与当前负载推荐数字员工
        ↓
原子写入该员工的任务队列（幂等）
        ↓
员工按队列执行
        ↓
任务终态后异步回写结果
```

## 关键特性

| 特性 | 说明 |
| --- | --- |
| 智能推荐 | 综合员工的**岗位、能力标签与负载**选择执行者 |
| 幂等入队 | 同一事件的并发请求只会入队一次，重复请求视为幂等命中 |
| 复用任务队列 | 直接写入现有任务队列，遵循「一员工一主任务」与权限网关 |
| 结果回写 | 队列终态后异步回写，不阻塞下一个任务的调度 |
| 历史审计 | 保留调度历史，便于追溯 |
| 失败重派 | 失败的任务可以重新派发 |

> [!TIP]
> 调度只是「派单」：每个任务真正执行时，仍会逐条经过权限网关，需要审批的命令照样会提示你。
