## 组成部分

| 组件 | 技术栈 | 职责 |
| --- | --- | --- |
| 桌面端 | Electron + React（Vite） | 启动内置后端，提供对话、员工管理、技能、审批与设置界面 |
| 本机后端 | Go（Gin） | 引擎适配、权限网关、任务队列、对话持久化、RemoteBridge |
| 平台数据 | SQLite（默认）/ MySQL 8（可选） | 员工、对话、消息、审批、队列与命令审计 |
| 工作引擎 | 本机 CLI | `claude`、`codex`、`agent`，在工作区内执行任务 |
| 远程中继 | Node.js + TypeScript + SQLite（Express） | 实例注册、指令信箱、缓存镜像、设备会话 |
| 移动端 | iOS App | 查看与继续对话、任务与审批、iOS 灵动岛 |
| macOS 灵动岛 | SwiftUI | 常驻胶囊，展示四态优先级与任务步骤 |

## 关键链路

### 对话：SSE 流式推送

任务开始后，引擎 stdout 中的 JSONL 被适配器转换为统一的事件（文本、工具、命令、用量、规划），经 SSE 推送到界面，同时写入数据库。即使浏览器断开，后端任务也不会被取消，稍后可以从持久化消息恢复。

### 移动端：出站长轮询

电脑与中继之间采用 **HTTP 长轮询，而不是 WebSocket**。电脑主动向中继发起长轮询领取指令、推送状态快照；**服务器永远不会主动连接你的电脑**，因此电脑不需要公网 IP，也不需要开放任何入站端口。

### 审批：同一条记录，多端处理

权限网关判定需要人工复核时，会生成一条待审批记录。桌面卡片、手机和灵动岛看到的是同一条记录，任一端做出决定后其余端同步收敛，**同一条审批只允许成功提交一次**。

## 设计理念

1. **不重复造引擎。** 充分利用各家 CLI 的原生能力（Session、Hook、Compact），平台只负责统一与治理。
2. **本机即真相。** 所有业务数据以电脑为准；中继只是缓存镜像与指令信箱，实例离线时手机明确提示，不会静默切换到其他电脑。
3. **安全默认。** 无法确认风险、审核服务异常、审批超时，一律按安全默认值处理——**不会默认放行**。
4. **诚实的状态。** 进度来自引擎报告的真实步骤，而非时间动画；事后观察到的命令不会被伪装成执行前拦截。
5. **只做必要的同步。** 镜像只包含远程端需要的数据，本机文件系统与完整引擎日志不会同步出去。
