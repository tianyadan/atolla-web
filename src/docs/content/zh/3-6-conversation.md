## 对话与会话

每位数字员工都有自己的对话，同一员工也可以有多个线程。电脑和手机打开时，会优先恢复**该实例下最近使用的员工及其最近会话**。会话必须与实例、员工的关系一起校验，不会跨实例复用。

## SSE 流式执行

```text
用户提交任务
        ↓
启动独立运行上下文（脱离 HTTP 请求）
        ↓
引擎 stdout JSONL → 统一事件
        ↓
SSE 广播 文本 / 工具 / 命令 / 用量 / 规划
        ↓
前端按消息与事件 ID 合并时间线 → 最终回答落库 + 终态通知
```

- 思考文本、工具调用、命令状态与最终回答**逐步**进入对话，不必等整个 CLI 进程结束；
- **SSE 断开不等于任务取消**，稍后可以从持久化消息恢复；
- 引擎可能先流式输出正文、最后再返回完整结果，前端会去重而不是重复追加。

## 任务规划

发送任务时开启「任务规划」，长任务的阶段和当前步骤会以结构化卡片展示：

| 阶段 | 含义 |
| --- | --- |
| planning | 正在制定计划 |
| running（step / total） | 正在执行第几步 |
| done | 成功完成 |
| failed / interrupted | 失败或被中断 |

进度来自**引擎报告的真实步骤**，不是按时间或 Token 估算的百分比；同一份规划状态也会同步到灵动岛。未开启任务规划时，流式对话、命令审批与结果保存照常生效。

## 任务队列

**一位员工同一时间只执行一个主任务。** 员工忙碌时你再发送任务，可以选择：

| 选项 | 行为 |
| --- | --- |
| 打断优先 | 新任务插到队头，并停止当前任务 |
| 加入队列 | 新任务以 `queued` 状态持久化，当前任务结束后自动领取 |

```text
queued → running → done / failed
手动 Stop → hold → 点击「继续队列」后恢复
```

- 正常结束会自动领取下一项；**手动 Stop 会暂停队列**，避免「刚停下又自动开始」；
- 只能修改或取消尚未执行的队列项；
- 队列不改变权限网关，每一项真正执行时仍要独立审批命令。

## 图片与附件

- 支持粘贴、拖入或选择图片，发送前可以预览、放大或删除；**单次最多 6 张**；
- 图片会在本地压缩保存，配置 OSS 后可同步为远程可访问地址；
- Claude 直接接收多模态附件；Codex / Cursor 优先通过工作区可读路径传递；
- Codex / Cursor 回答中的本机图片路径会在主目录或工作区白名单内解析回显，并拒绝 `.ssh`、`.aws`、Keychains 等敏感目录。

## 对话时间线

时间线不只展示问答，还把工具调用、命令审批、执行结果、附件和任务终态放在同一条可追溯的线上：

- 执行完成的命令默认折叠，待审批命令保持展开；
- **重试是新的执行轮次**，旧轮次保留为历史，不覆盖原来的错误；
- 任务耗时以服务端时间为准，终态后固定为持久化耗时。
